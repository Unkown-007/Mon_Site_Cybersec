# 🎵 Musiques du lecteur — UnknownX-077

Dépose ici **5 fichiers `.mp3`** (musique cyberpunk / synthwave) avec **exactement** ces noms :

```
public/music/neon-drive.mp3
public/music/midnight-protocol.mp3
public/music/data-stream.mp3
public/music/ghost-in-the-wire.mp3
public/music/red-moon.mp3
```

Le lecteur (bouton ♪ en bas à gauche) les lira automatiquement.
**Tant qu'un fichier est absent, le lecteur bascule sur la musique synthétisée** (générée en local) — donc il n'est jamais muet.

## Où trouver de la musique libre de droits (gratuite, légale)

- **Pixabay Music** — https://pixabay.com/music/search/cyberpunk/ (licence Pixabay, gratuit, sans attribution)
- **Free Music Archive** — https://freemusicarchive.org/genre/Electronic/ (filtrer CC0 / CC-BY)
- **Patrick de Arteaga** — https://patrickdearteaga.com/ (synthwave, CC-BY)
- **Kevin MacLeod / incompetech** — https://incompetech.com/ (CC-BY)
- **OpenGameArt** — https://opengameart.org/ (musiques de jeu, souvent CC0)

> Télécharge un morceau, renomme-le selon la liste ci-dessus, place-le dans ce dossier.
> Pas besoin de redémarrer le serveur : recharge la page (Ctrl+F5).

## Changer les titres / fichiers

Édite la liste `TRACKS` dans `src/components/MusicPlayer.tsx`.
